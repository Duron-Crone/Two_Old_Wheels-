# Two Old Wheels

Site de l'atelier **Two Old Wheels** : réparation, entretien, restauration, préparation et vente de
motos anciennes, à Saint-Martin-d'Uriage, au-dessus de Grenoble.

**https://www.twooldwheels.fr**

## Mettre à jour le site

Les textes, les photos, les motos en vente et les coordonnées se modifient depuis l'espace
d'administration, à l'adresse `/admin`. Chaque enregistrement est mis en ligne automatiquement en
quelques minutes, sans intervention. Le guide destiné à l'atelier est remis à part.

## Organisation

| Dossier | Contenu |
|---|---|
| `src/content/` | les textes du site, un fichier par rubrique de l'administration |
| `src/assets/photos/` | les photos |
| `src/pages/` | les pages |
| `src/components/` | les éléments réutilisés d'une page à l'autre |
| `public/` | ce qui est servi tel quel : configuration du serveur, favicon, image de partage |
| `scripts/` | les contrôles automatiques passés avant chaque mise en ligne |
